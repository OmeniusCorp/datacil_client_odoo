Preguntas frecuentes

Lo que suelen preguntar

¿Sirve para talleres mecánicos?

Sí, y combina con el módulo de Flota para consultar el vehículo por placa.

¿Bloquea la reparación?

No: solo informa, el flujo de la orden no cambia.

¿Cuándo consume créditos?

Solo al pulsar Verificar en Datacil.

¿Se instala aparte?

No. Se instala solo cuando tienes Reparaciones y Datacil Client.
