Para el negocio

Cada campo que no escribe, es una venta que no pierdes.

El formulario de dirección es donde más carritos se abandonan.

01

Menos carritos abandonados

El formulario deja de ser una barrera: el cliente escribe su identificación y el resto aparece.

02

Tú decides el costo

Modo gratuito (solo el nombre, sin consumir créditos) o modo completo con dirección y contacto.

03

Privacidad por diseño

Nunca expone datos de otros clientes de tu base y limita las consultas por visitante para evitar abusos.

Cómo se activa

Tres pasos en tu tienda.

01

Enciende la opción

En Sitio web → Configuración → Datacil activa el autocompletado y elige el modo.

02

El visitante escribe su identificación

Al salir del campo se consulta la información en Datacil.

03

Los campos vacíos se completan

El cliente revisa, confirma y termina su compra; nunca se pisa lo que ya escribió.

Preguntas frecuentes

Lo que suelen preguntar

¿Consume créditos siempre?

Solo en el modo completo. El modo "solo nombre" usa un servicio gratuito.

¿Puedo activarlo en un solo sitio?

Sí, la opción es por sitio web.

¿Un bot puede gastar mis créditos?

Hay un límite por sesión y se validan los formatos antes de consultar.

¿Se instala aparte?

No. Se instala solo cuando tienes Sitio web y Datacil Client.
